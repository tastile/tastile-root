## Verification (binding, per ticket)

- tastile-root: `pwsh -NoProfile -File .\scripts\check-agent-environment.ps1`
- tastile-web (各 ticket): `bun run check` + `bun run check:release`
- pre-commit review: `Invoke-PreCommitReview.ps1` (claude/codex → 別 agent reviewer)
- release PR: `verify-release.ps1 -Execute -ApiUrl ... -RunNamespace ...`

## 環境前提 (host portability)

- primary host: Windows + WSLC (`HARNESS.md §9-3`)
- macOS / Linux / cloud sandbox: wslc / Linux runtime 経由で同等検証
- この host (Linux WSL2, pwsh 不在): コミット実行不可。**コミットは Windows
  primary host で実行すること**
