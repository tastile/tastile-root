## C. core v1 文書で発見した文字化け

`v1/00-glossary.md`、`v1/03-time-and-windows.md`、`v1/14-read-model-and-endpoint.md` の 20 箇所で、識別子先頭文字が

`expectedRevision` `failed_at` `frames[]` `rules[]` `baseline` `examWeekMode` `end` `PointReference` `acceptedAt` `aggregate`
`null` / `0` を Rust / migration の識別子と突き合わせて復元した (core branch 199)。**意味の変更ではない**。
なお scaffold 時点 (8a621ff) で既に 13 箇所が壊れており、以降 3 年間検出されなかった。
